## Generator-coverage note (per row — boundary + adversarial input shapes)

- **`P-SM-1 — wiki_cross.*** Two live wikis `A≠B`, each with at least one dedicated cited document (a document created in `A` must not be cited by a fact "under `B`" — cite only each wiki's own document). Boundary: same `fact_key` string committed under both wikis; keys differing only by case/length; empty `value`; distinct document_ids per wiki; empty (`""`) fact keys are excluded (schema row owns them). Adversarial: a fact under `A` whose `document_id` belongs to `B` is **not** a valid input (grounds on a real node in `A`); assert `get_fact(B, k)` never yields `A`'s `document_id`.
- **`P-SM-2 — dedup_keys.*** Pre-seed one committed fact per key before the duplicate attempt. Boundary: duplicate with identical value vs. a *different* value; key of max typical length; two keys that differ only by trailing space. Adversarial: duplicate attempt `propose_candidate_fact` (must be `Err(ConflictError)`, not `accepted`) and duplicate `create_fact` (must be `Err(ConflictError)`); assert the pre-existing value is unmodified after the duplicate attempt.
- **`P-SM-3 — ground_cites.*** Seed ≥1 real node; generate citation sets of size 1, 2, and up to ~5 (dedup duplicates within the set — first-appearance dedup is green). Boundary: exactly 1 citation; repeated tuple `(d,n)` appearing twice in the input (must dedup). Adversarial: a `(docId,nodeId)` where `nodeId` does not exist in the (existing) document; a citation to a **deleted** document (sequential delete-then-propose proxy); empty citation set (→ schema/min-citation, may be `rejection.field=="citations"` on propose or `ValidationError` on create).
- **`P-SM-4 — del_cited` [GREEN — held].*** Seed a committed fact citing node `(D,n)` of a real document, then `delete_document(D)`. Adversarial: delete the *uncited* document in the same wiki (must still succeed — the invariant is specifically about the **cited** document); a fact citing only one of two documents, delete the cited one vs. the uncited one; delete a document cited by two distinct facts.
- **`P-SM-5 — ghost_wiki` [GREEN — held].** Use a `WikiId` that was never `create_wiki`-d. Run the full fact surface against it: `get_fact`, `list_facts`, `create_fact` (with a *real* document_id argument — the wiki check must fire before/independent of document existence), `update_fact`, `propose_candidate_fact`. Boundary: ghost id that resembles an existing id (e.g. a real wiki id with an appended char).
- **`P-IM-1 — blank_inputs` (GREEN — held: `""` AND whitespace-only `" "`).** Two blank shapes: the empty string `""` and the single-space `/multi-space` / tab-only string. Apply to each of `fact_key` and `value` on `create_fact`, `value` on `update_fact`, and each of `fact_key`/`value` on `propose_candidate_fact`. Boundary: a `value` of `" a "` (non-blank after trim) — note trimming is **not** assumed green; the invariant only asserts *blank-only* rejection, and the trimmed round-trip is deliberately **not** asserted (unverified on today's impl). Adversarial: blank `fact_key` + non-blank `value`; blank `value` + valid `citations`; a valid create followed by a blank `update_fact` value must leave the stored fact unchanged.
- **`P-TP-1 — upd_idem`.*** Read-before-update on a persisted fact, then update. Boundary: update keeping the same value (idempotent value) — key must still be preserved and `updated_at >=` prior; update to the exact same citation set; update replacing citations entirely. Adversarial: attempt `update_fact` on a key that was never created (→ `Err(DocumentNotFound)` — this is an identity-preservation *negative* check, not a fail-state row); update with blank `value` exercises `P-IM-1`, so keep this row's generator on non-blank values to test the preservation leg specifically. Note the `created_at` field does not exist on `Fact`, so no assertion may reference it.
- **`P-TP-2 — page_walk`.*** Commit a variable count of facts (0, 1, a boundary like 5, and near/at `page_size` multiples). Boundary: `page_size=1` (steppiest), `page_size=100` (max), a fact count that is an exact multiple of `page_size` (last page full) and one-off (last page partial); `page=1` with an empty wiki → `total==0`, `items==[]`. Adversarial: `page=0` and `page_size=0` and `page_size=101` → each must be `Err(ValidationError)` (bounds are part of the invariant and green); the default (all-`None`) filter enumerates the entire set and doubles as the reference union.

## API notes for the TestWriter

- **Seam / invocation.** `Store` implements `RagStore`; build shared store as `Arc::new(Store::new())` (as the integration suite does). All fact-surface methods are `async` (trait declares `-> impl Future<…> + Send`; impls are `async fn`) — every property assertion awaits a `Result<…, StoreError>`. Test runtime is `#[tokio::test]`.
- **Concrete signatures (exact, from `src/store/mod.rs`):**
  - `fn create_fact(&self, wiki_id: &WikiId, document_id: &DocumentId, fact_key: &str, value: &str, citations: &[(DocumentId, NodeId)]) -> Result<Fact, StoreError>` — manual override (§4.3.1). Failures on GREEN: `ValidationError` (empty `factKey`/`value`, empty `citations`), `ConflictError` (duplicate wiki-unique key). Unknown-wiki uniform behavior is held (H5 — FIXED to `WikiNotFound`).
  - `fn get_fact(&self, wiki_id: &WikiId, fact_key: &str) -> Result<Fact, StoreError>` — read-back accessor.
  - `fn list_facts(&self, wiki_id: &WikiId, filter: &ListFactsFilter) -> Result<FactList, StoreError>` — pagination; `ListFactsFilter { state: Option<DocState>, page: Option<u64>, page_size: Option<u64> }` (implements `Default`; default = no filter). Bounds: `page >= 1`, `1 <= page_size <= 100` (violations → `ValidationError`, green). `state` filters by the **containing Document's** `DocState`.
  - `fn update_fact(&self, wiki_id: &WikiId, fact_key: &str, request: &UpdateFactRequest) -> Result<Fact, StoreError>` — `UpdateFactRequest { value: String, citations: Vec<(DocumentId, NodeId)> }`. Manual declaration still passes the deterministic gate (§4.3.2a.3).
  - `fn propose_candidate_fact(&self, wiki_id: &WikiId, candidate: &CandidateFact) -> Result<ProposalOutcome, StoreError>` — `CandidateFact { fact_key, value, citations }`; `ProposalOutcome { accepted: bool, fact: Option<Fact>, rejection: Option<Rejection> }`; `Rejection { code, field, message }` with `field ∈ {"fact_key","value","citations"}`. Accepted → committed (retrievable via `get_fact`). Schema failures → `Ok(accepted:false) + rejection`, nothing committed. Spec-pinned fail-states surface as `Err`: dangling citation → `ValidationError("citation does not resolve")`; duplicate key → `ConflictError`.
  - `fn merge_facts(&self, fact_keys: &[String], options: &MergeFactsOptions) -> Result<Fact, StoreError>` (§4.2.9.1 — also writes `fact_store`; relevant to `P-SM-2`/`P-TP-1` if you extend, since it refreshes `updatedAt` and unions citations).
  - `fn get_query_audit_log(&self) -> Result<Vec<QueryAuditEntry>, StoreError>` (§4.3.4) — not needed by these invariants.
- **`Fact` value shape (frozen, do not extend):** `fact_key: String, value: String, document_id: DocumentId, node_id: NodeId, updated_at: String (ISO-8601 UTC), citations: Vec<(DocumentId, NodeId)>`. `node_id` is derived (see suite: `fact-<key>`). **There is no `created_at` field — the §4.3 `Fact` type cannot expose creation time, so no invariant may reference it.**
- **Setup dependency:** a citation `(d, n)` must resolve to a real node of a real document. Follow the suite helpers: `create_wiki(name)` → `create_document(wiki, CreateDocumentRequest{…})` → `update_document` to apply a graph containing the cited `Node { node_id, kind: Content, … }` (the suite's `content_only_graph` seeding = doc-head + at least one content node). Facts cite `(document_id, node_id)` of seeded nodes. A citation that does not resolve (ghost document/node, or a deleted document) exercises the grounding leg.
